# Day 2 · Mon Aug 3

**Built:** Ingestion stage for the retrieval project. Loads the corpus, collapses duplicates, normalizes whitespace, and emits a profile that accounts for every source row. 5 tests passing. Also made the package properly installable, which taught me more about Python packaging than the code itself did.

**Learned:** The corpus is multi-label flattened into rows. 11,970 rows are actually 10,588 distinct judgments, because a judgment tagged with two case types appears twice with byte-identical text. Naive ingestion would have embedded 13% of the corpus twice, paid double the compute, and returned the same judgment in multiple result slots without ever raising an error.

Second thing, smaller but sharper: I wrote a comment saying I collapse runs of spaces, and the regex I actually wrote only collapsed tabs. The code ran fine and produced confident wrong numbers. The only reason I caught it was predicting the median length would drop and noticing it barely moved. Data bugs do not crash, they just quietly lie.
