# Explain videos

Five minutes. No notes. One take. Recorded every Saturday, walking through code I wrote that week.

**Why this exists:** commits can be generated, READMEs can be ghostwritten, benchmarks can be copied. Someone explaining their own architecture cold, every week for six months, cannot be. This is the part of the trail that is not fakeable.

The early ones are rough. That is deliberate. I do not re-record, because the arc from the first video to the last is itself the point.
